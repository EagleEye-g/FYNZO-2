# FYNZO

Offline English → Urdu dictionary app.

- Premium pink / black / white UI
- Local English word index
- Bundled offline English→Urdu exact-meaning core
- No invented fallback meanings
- Service worker cache updated to v2

The bundled meaning core is intentionally conservative. The full 500,000-word expansion requires a redistributable/licensed English→Urdu lexical dataset; FYNZO should not copy proprietary dictionary content without permission.


## Online lookup
FYNZO v3 keeps the bundled English→Urdu meanings offline and, when internet is available, supplements searches with Dictionary API (English definitions) and MyMemory (English→Urdu translation). Online results are clearly labeled and are not used to replace bundled meanings.
